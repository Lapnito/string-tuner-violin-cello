# String Tuner: Violin & Cello

Penala Android percuma dan luar talian untuk 60 alat muzik, dengan dron, metronom dan latihan intonasi. Audio mikrofon dianalisis secara langsung dan tidak dirakam.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
