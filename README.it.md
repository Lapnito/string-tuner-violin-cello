# String Tuner: Violin & Cello

Accordatore Android gratuito e offline per 60 strumenti, con bordone, metronomo e allenamento dell'intonazione. L'audio del microfono viene analizzato dal vivo e non registrato.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
