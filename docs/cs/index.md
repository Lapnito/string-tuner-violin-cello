# String Tuner: Violin & Cello

Bezplatná offline Android ladička pro 60 nástrojů s dronem, metronomem a tréninkem intonace. Zvuk mikrofonu se analyzuje živě a nenahrává se.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
