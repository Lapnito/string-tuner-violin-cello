# String Tuner: Violin & Cello

Bezpłatny tuner offline na Androida dla 60 instrumentów, z dronem, metronomem i treningiem intonacji. Dźwięk mikrofonu jest analizowany na żywo i nie jest nagrywany.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
