# String Tuner: Violin & Cello

Kostenloses Offline-Stimmgerät für Android mit 60 Instrumenten, Bordun, Metronom und Intonationstraining. Mikrofonsignale werden live analysiert und nie aufgezeichnet.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
