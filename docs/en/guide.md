# Getting started with String Tuner: Violin & Cello

String Tuner: Violin & Cello is a free offline android tuner for 60 instruments, with drone, metronome and intonation training. microphone audio is analysed live and never recorded. It is published by lapnito.cz s.r.o. and was last verified from the public store listing on 2026-10-01.

## Start with the app itself

1. Install the verified store build.
2. Open the app and review its on-screen setup.
3. Add only the information needed for the task.
4. Check exported or displayed results before relying on them.

## Keep the limitation visible

A phone tuner is a practice aid. Room noise, microphone quality and playing technique can affect detection.
