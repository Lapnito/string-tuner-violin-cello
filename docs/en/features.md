# Features in String Tuner: Violin & Cello

String Tuner: Violin & Cello is a free offline android tuner for 60 instruments, with drone, metronome and intonation training. microphone audio is analysed live and never recorded. It is published by lapnito.cz s.r.o. and was last verified from the public store listing on 2026-10-01.

## Verified feature list

| # | Store-listed capability |
|---|---|
| 1 | Tuning profiles for 60 instruments, including bowed, plucked, wind and world instruments |
| 2 | Reference pitch from 392 to 466 Hz and presets for 415, 442 and 443 Hz |
| 3 | Drone, tanpura, shruti box, metronome, tuning fork and pitch pipe |
| 4 | Intonation trainer with scale practice and sharp-or-flat heatmap |
| 5 | Stand mode and teacher mode with QR setup sharing |
| 6 | Live on-device microphone analysis without recording |

## Feature limits

A phone tuner is a practice aid. Room noise, microphone quality and playing technique can affect detection.
