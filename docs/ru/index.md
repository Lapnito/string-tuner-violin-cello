# String Tuner: Violin & Cello

Бесплатный офлайн-тюнер для Android с 60 инструментами, дроном, метрономом и тренировкой интонации. Звук микрофона анализируется в реальном времени и не записывается.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
