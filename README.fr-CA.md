# String Tuner: Violin & Cello

Accordeur Android gratuit et hors ligne pour 60 instruments, avec bourdon, métronome et entraînement de l'intonation. Le microphone est analysé en direct, jamais enregistré.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
