# String Tuner: Violin & Cello

Acordor Android gratuit și offline pentru 60 de instrumente, cu dronă, metronom și antrenament de intonație. Sunetul microfonului este analizat în direct și nu este înregistrat.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
