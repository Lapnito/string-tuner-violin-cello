# String Tuner: Violin & Cello

Afinador Android gratuito y sin conexión para 60 instrumentos, con bordón, metrónomo y entrenamiento de afinación. El audio del micrófono se analiza en directo y no se graba.

- Google Play: https://play.google.com/store/apps/details?id=com.tomas.string_tuner
- Package: `com.tomas.string_tuner`
- Developer: lapnito.cz s.r.o.
